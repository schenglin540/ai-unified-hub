# GitHub Public Presentation

## Final project name

**OpenAPI Playground** remains the project name. The repository name should remain `openapi-playground` unless its owner explicitly selects a different candidate.

## GitHub repository description candidates

Choose one after creating the real repository. Each option reflects implemented capabilities only.

1. **A local-first playground for testing OpenAI-compatible chat APIs, comparing models, and diagnosing failures.**
2. **Test OpenAI-compatible providers from your browser with local history, model comparison, streaming controls, and safe diagnostics.**
3. **A privacy-first developer workbench for OpenAI-compatible API requests, model comparison, and local failure analysis.**
4. **A local workbench for OpenAI-compatible chat-completion requests, model comparison, response inspection, and diagnostics.**
5. **OpenAI-compatible API testing with browser-local credentials, streaming inspection, model comparison, and developer diagnostics.**

## Suggested topics

Apply these GitHub topics after the repository exists:

`ai`, `llm`, `openai-compatible`, `api`, `api-testing`, `playground`, `developer-tools`, `model-comparison`, `diagnostics`, `react`, `typescript`, `vite`.

## Metadata and social preview

The application defines a title, description, favicon, Open Graph title/description/image, and Twitter title/description/image. The social image is the reviewed Dashboard capture, not generated marketing art. `canonical` and `og:url` are intentionally absent until the repository owner confirms the final public domain; do not add a guessed GitHub Pages, hosting, or demo URL.

## Apply after repository creation

1. Create the repository under the selected owner without adding a conflicting README, license, or ignore template.
2. Set the selected description and the listed topics in the repository settings.
3. Add the actual repository URL to `package.json` fields `repository`, `bugs`, and `homepage` in a focused follow-up commit.
4. Confirm GitHub Actions has completed successfully before making the first public release.
